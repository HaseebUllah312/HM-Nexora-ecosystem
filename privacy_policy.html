1. Overview & Commitment

HM Nexora ("we", "our", or "us") provides academic productivity tools, lecture navigation utilities, and study resources for university students. This Privacy Policy details our strict policies and procedures regarding the collection, handling, storage, processing, and sharing of user data for our web platform (https://www.hmnexora.app) and our Chrome Browser Extension (HM Nexora – Smart LMS Companion).

🔒 Core Guarantee: We do NOT sell, rent, monetize, or trade any personal user data. We do NOT serve third-party targeted advertisements or transfer user data to data brokers. All data handling is strictly limited to providing the core academic features requested by the user.

2. User Data Collection & Access

We believe in data minimization. We only access the minimal data required to execute user-requested features:

A. Academic & LMS Information (Local Access)

  • Student Identification & Enrolled Courses: Extracted locally from the student's active session DOM on vulms.vu.edu.pk (such as Student ID e.g., BC230406936 and enrolled course codes e.g., CS201, CS301) to organize relevant study files and enable course chat rooms.
  • Video Playback Timestamps: Local video progress timestamps to facilitate automated resume and skip navigation across official video lectures.

B. Authentication Data (Google Identity OAuth 2.0)

  • Email Address & Basic Profile Name: Accessed via the standard Chrome identity API solely to authenticate the student, manage their secure vault session, and verify legitimate student access.

C. Calendar & Cloud Drive Sync (User-Authorized)

  • Google Calendar: Access to https://www.googleapis.com/auth/calendar.events strictly used to add academic deadlines (assignments, GDBs, quizzes) to the user's personal calendar upon explicit user request.
  • Google Drive App Data: Access to https://www.googleapis.com/auth/drive.appdata strictly used to create an isolated, encrypted backup of the user's own study notes and settings in their private Google Drive storage.

3. User Data Handling & Usage

All data collected or accessed is used exclusively for the following academic functions:

  • Enabling seamless lecture navigation and study checklist tracking.
  • Organizing past papers, solved files, and formula sheets tailored to the student's enrolled courses.
  • Executing anti-plagiarism verification and formatting student assignments in accordance with university submission standards.
  • Synchronizing user study preferences across devices via encrypted local/cloud cache.

4. User Data Storage, Security & Retention

  • Local Storage: By default, user preferences, lecture progress, and offline notes are stored locally on the user's device using chrome.storage.local.
  • Transmission Security: All network requests to our API endpoints (https://www.hmnexora.app and Cloudflare Edge) are strictly encrypted in transit using TLS 1.3 / HTTPS.
  • Data Retention: Stored preferences are retained only as long as the student actively utilizes the extension. The user can clear all stored data at any time via the extension options panel.

5. User Data Sharing & Third-Party Disclosure

We maintain a strict zero-sharing policy:

  • No Sale of Data: User data is never sold to third parties under any circumstances.
  • No Ad Targeting: No data is transferred to advertising networks, tracking pixels, or data brokers.
  • Authorized Service Providers: We only interface with essential infrastructure providers:
    • Google APIs: For OAuth 2.0 authentication, Google Calendar event creation, and Google Drive app-data synchronization.
    • Cloudflare & Supabase: For secure, encrypted serverless API edge routing and peer-to-peer classmate messaging.

6. Google API Services User Data Policy Compliance

7. User Control & Data Deletion Rights

Users have complete control over their personal data:

  • Instant Local Deletion: You can purge all locally cached course data and settings at any time by opening the Extension Options page and clicking "Clear Local Cache".
  • Revoke Google Access: You can revoke Google OAuth permissions at any time via Google Account Security Settings.
  • Full Account Deletion Request: To request the complete deletion of any cloud-synced account profile, contact us at haseebsaleem312@gmail.com and all associated records will be permanently expunged within 24 hours.
